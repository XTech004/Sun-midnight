# ระบบสั่งอาหาร Sun Midnight

ระบบสำหรับร้านเดียว ใช้ Node.js 24 และฐานข้อมูล SQLite บนเครื่องร้าน ลูกค้าและพนักงานเชื่อมต่อผ่าน Wi-Fi เดียวกัน ไม่ต้องสมัครบริการรายเดือน โค้ดมีเมนูตัวอย่างซึ่งแคชเชียร์เพิ่มและเปิด/ปิดการขายได้

## เริ่มต้น

1. ติดตั้ง Node.js เวอร์ชัน 24 และเชื่อมคอมพิวเตอร์ร้านกับเครือข่าย Wi-Fi
2. เปิดเทอร์มินัลในโฟลเดอร์โปรเจกต์ แล้วรัน `npm install` เพื่อติดตั้งตัวสร้าง QR จากนั้นรัน `npm start`
3. บนเครื่องร้านเปิด `http://localhost:3000` เลือก “สำหรับพนักงาน” แล้วตั้งรหัสผ่านแม่ครัวและแคชเชียร์อย่างน้อย 8 ตัวอักษร
4. เปิด URL ที่โปรแกรมแสดงเป็น `Wi-Fi: http://...:3000` จากเครื่องร้าน เข้าแคชเชียร์ แล้วสร้าง QR สำหรับแต่ละโต๊ะ พิมพ์หรือนำภาพไปติดโต๊ะ ห้ามใช้ localhost ใน QR เพราะโทรศัพท์จะเปิดไปยังตัวเอง
5. ลูกค้าเชื่อม Wi-Fi เดียวกัน สแกน QR เลือกอาหารและส่งคำสั่งซื้อ แม่ครัวเปิดหน้าพนักงานเพื่อรับและเปลี่ยนสถานะ แคชเชียร์บันทึกการชำระเงินและดูรายการ

เครื่องร้านต้องเปิดโปรแกรมไว้ตลอด และอุปกรณ์ในเครือข่ายต้องเชื่อมต่อกันได้ อาจต้องอนุญาต Node.js ในไฟร์วอลล์ของเครื่องร้าน หาก IP เปลี่ยน ต้องสร้าง QR ใหม่ ควรตั้ง IP ภายในเครือข่ายให้คงที่

## ข้อมูลและข้อจำกัด

ข้อมูลเก็บใน `data/restaurant.sqlite` บนเครื่องร้าน ควรสำรองไฟล์เมื่อหยุดโปรแกรม ข้อมูลชื่อเป็นทางเลือก ไม่ควรเก็บข้อมูลที่ไม่จำเป็น ระบบบันทึกว่าชำระแล้วด้วยมือ ไม่เชื่อมระบบชำระเงินจริงหรือเครื่องพิมพ์ใบเสร็จ หน้าพนักงานแสดง 500 ออเดอร์ล่าสุด

เป็นระบบเริ่มต้นสำหรับเครือข่ายภายใน ใช้ HTTP จึงไม่ควรเปิดพอร์ตสู่อินเทอร์เน็ตหรือใช้ Wi-Fi สาธารณะ รหัสผ่านและข้อมูลอาจถูกดักฟังภายในเครือข่ายได้ ควรเพิ่ม HTTPS ระบบจัดการบัญชีและการสำรองข้อมูลก่อนใช้งานจริงกับข้อมูลส่วนบุคคล การใช้งานพึ่งพาเครือข่ายและเครื่องร้าน ไม่มีการรับประกันว่าจะไม่มีค่าใช้จ่ายด้านเครื่อง อุปกรณ์ หรืออินเทอร์เน็ต
