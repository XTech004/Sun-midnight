# รูปสลิปการชำระเงิน

สำหรับฐานข้อมูลเดิม ให้เจ้าของระบบเปิด Supabase SQL Editor แล้วรัน `supabase/payment-slips.sql` หนึ่งครั้ง ก่อนใช้หน้าเว็บรุ่นที่มีฟีเจอร์นี้ สคริปต์เพิ่มตารางใน schema ส่วนตัวและฟังก์ชันสำหรับแคชเชียร์ ไม่ต้องรัน schema.sql ซ้ำ

หลังตรวจสอบยอดเงินเข้า แคชเชียร์เลือก “ถ่ายรูปสลิปและยืนยัน” เพื่อถ่ายหรือเลือกรูป ระบบย่อรูปเป็น JPEG ไม่เกิน 1 MiB แล้วบันทึกพร้อมตั้งสถานะชำระในธุรกรรมเดียว รูปสลิปเรียกดูได้จากปุ่ม “ดูสลิป” โดยแคชเชียร์ที่เข้าสู่ระบบเท่านั้น เงินสดยังใช้ปุ่มบันทึกว่าชำระแล้วได้ตามเดิม ปุ่มดูสลิปจะแจ้งหากรายการนั้นไม่มีรูป

รูปเป็นเพียงหลักฐานประกอบ ไม่ใช่การตรวจสอบยอดโอนอัตโนมัติ ให้ตรวจสอบเงินเข้าจากบัญชีร้านก่อนยืนยัน ปัจจุบันระบบคิดและบันทึกการชำระแยกตามออเดอร์ และไม่รวมบิลหลายออเดอร์

รูปเก็บในฐานข้อมูล PostgreSQL จึงใช้พื้นที่ฐานข้อมูลและเพิ่มขนาดไฟล์สำรอง ควรกำหนดระยะเวลาจัดเก็บและตรวจสอบพื้นที่สม่ำเสมอ รวมทั้งรักษาไฟล์สำรองให้เป็นความลับ การถ่ายภาพต้องใช้เบราว์เซอร์และอุปกรณ์ที่รองรับ
